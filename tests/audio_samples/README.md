# Fichiers audio de démonstration

Ce dossier contient 3 fichiers de test, un par classe de sentiment attendue :

| Fichier | Sentiment attendu |
|---|---|
| `exemple_positif.wav` | positif |
| `exemple_neutre.wav` | neutre |
| `exemple_negatif.wav` | négatif |

⚠️ **Important** : les fichiers fournis par défaut dans ce dépôt sont des
**tonalités synthétiques** (générées par script, sans parole) servant
uniquement à valider que le pipeline technique fonctionne de bout en bout
(chargement, prétraitement, appel des modèles, gestion des formats).

Pour une véritable démonstration métier, **remplacez ces fichiers par de
vrais enregistrements vocaux en français** (voix humaine ou TTS) exprimant
respectivement un sentiment positif, neutre et négatif, en conservant les
mêmes noms de fichiers.
